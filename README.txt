30-Day Fitness Reset — Aug 24 to Sep 22, 2026

FEATURES
• One page automatically opens the current workout.
• Check every exercise and complete the day.
• Progress persists in the browser on that device using localStorage.
• 30-day calendar and progress dashboard.
• One direct YouTube demonstration link per exercise (no search pages).
• Installable as a Home Screen web app after it is hosted.

IMPORTANT
Progress in this version is stored locally. Do not clear the site's browser data if you want to keep it.
For cross-device/cloud progress, a backend/account system would be needed.

HOSTING
Upload the contents of this ZIP to a static host such as GitHub Pages.
